🐷 Can I host this website on Porkbun?

Yes, absolutely! This is a static HTML site that loads Tailwind CSS from a CDN, so it can be hosted without a server-side application.

Option A: Porkbun Static Hosting (Direct)

Upload index.html to Porkbun’s Static Web Hosting panel under your domain dashboard. Visitors still need internet access to load the Tailwind CDN.

Option B: Free CDN Hosting + Porkbun DNS (Recommended)

Host the file on Cloudflare Pages or GitHub Pages for free global CDN delivery, then point your Porkbun domain's CNAME / ALIAS records to it.
